TRANSMISSIONS // dev log

2026.10.25UI

The interface overhaul, part one

The start screen, the star maps, the spell book and the hangar rebuilt.

The game now opens on a title screen with unlimited saves and a new-world page where you pick or design the galaxy's shape. The galaxy map became a holo starchart and the system map a tilted orrery you can zoom onto planets and moons. The Nano Mage's spell book got a beginner stack view, a grid view and a test range. Ship building moved to a full-screen hangar over the system you're parked in, with outside, blueprint, inside and details views.
